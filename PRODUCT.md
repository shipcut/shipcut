# shipcut: продукт

Этот файл описывает, что мы строим и чего не строим. Он меняется редко.
Порядок работ лежит в `ROADMAP.md`, детали текущего этапа в `docs/prd/`.
Правила для агента и словарь терминов лежат в `AGENTS.md`.

## Что это

`shipcut` записывает, как веб-приложение проходит сценарий, и превращает запись
в ролик, который не стыдно выложить. Сценарий лежит в репозитории рядом с
кодом, поэтому ролик можно перезаписать на каждом релизе, а ссылка на него
остается прежней.

## Обещание

Демо-видео, которое обновляется с каждым деплоем.

## Для кого

Маленькие SaaS-команды и одиночные основатели, у которых уже есть Playwright
или кто готов написать сценарий на TypeScript. Покупает тот, кто отвечает и за
код, и за маркетинг.

Не для кого: нетехнические маркетологи, которым нужен редактор с таймлайном.

Сценарий пишет клиент, у себя в репозитории. Чаще всего не руками, а своим
кодовым агентом (Claude Code, Cursor, Codex) по нашему скиллу
`skills/shipcut/SKILL.md`: агент видит исходники приложения и пишет главы,
селекторы и маску лучше, чем угадал бы кто-то по URL, а человек проверяет
сценарий в PR, как любой код. ИИ на нашей стороне для этого не нужен: он
требовал бы доступа к приложению клиента, стоил бы нам денег на модели и
давал бы невоспроизводимый ролик. Поэтому скилл это часть продукта, а не
приложение к нему: его качество решает, сколько стоит клиенту первый ролик
(решено 2026-10-07).

## Чем отличаемся

Ручные рекордеры требуют перезаписи руками при каждом изменении интерфейса.
У нас ролик воспроизводим: тот же сценарий дает тот же ролик, а изменился
интерфейс - изменился и ролик, без участия человека.

## Как получается ролик

Решено на этапе 1.

- Плавность дает только покадровый рендер: Chromium рисует каждый кадр на
  виртуальных часах, и анимации страницы попадают в ролик целиком, какой бы
  медленной ни была машина. Он собран и проверен на Linux, Windows не проверялся; на macOS Chrome
  не дает управлять кадрами, и там запись идет по настенным часам. Поэтому
  основной путь продукта это CI-раннер клиента.
- Все, что движется поверх страницы (указатель, нажатия, подписи, зум, рамка),
  рисует оформление по журналу событий, а не страница. Так оно не зависит от
  того, как быстро рисуется страница, и его можно переделать без нового
  прогона.
- Сначала desktop: ролики для X и Threads пишутся с десктопной версии сайта.
  `story` идет крупной карточкой.

## Рядом

Поле плотное, на 2026-10-07 видны три группы.

- Агент снимает по промпту или сам изучает код: Clueso, Demosmith, Ultrademo
  (локально, Apache-2.0, следит за GitHub и Linear и говорит, какие сцены
  изменились), Moonjar (снимки и ролики, MCP для Mac), DemoFly (агент изучает
  код и проходит приложение, ролик с озвучкой, CLI, плагин Claude Code и CI,
  бесплатный тариф). Красиво, но прогон невоспроизводим.
- Сценарий в репо, рендер в CI, open source без сервиса: AutoDemo (MIT,
  сценарии на YAML, шаги Playwright, `video.mp4` с указателем и подсветкой
  кликов, интерактивный разбор, GitHub Action пересобирает ролики на каждый
  merge, называет себя "demos as code"), demowright (шаги в JS-объекте,
  титры, указатель, зум, рамка, три формата из одной записи),
  playwright-recast (ролик из трейса Playwright, озвучка, субтитры из SRT),
  argo (Playwright плюс озвучка Kokoro).
- Ручные рекордеры и редакторы: Screen Studio и его открытые клоны, Shots
  (shots.so: макеты и анимированные ролики к запускам; из-за него имя
  `shots` нам не подходит).

Спрос на 2026-10-07, скачивания из npm за месяц: playwright-recast 33 105,
demowright 214, demofly 197; у AutoDemo 6 звезд на GitHub с июня 2026. Число
playwright-recast первый настоящий признак, что ролик из Playwright людям
нужен; часть скачиваний дают установки в CI, так что людей меньше.

Вторая группа это мы без сервиса, а AutoDemo уже делает наш этап 3: Action,
который пересобирает ролик после merge. Ни у кого нет стабильной ссылки,
плеера и истории прогонов. Наше отличие: покадровый рендер на виртуальных
часах, поэтому ролик плавный и на слабом раннере; оформление уровня Moonjar
поверх страницы; сценарий на TypeScript пишет кодовый агент клиента по
скиллу; и сервис. "Demos as code" как термин занят AutoDemo, им не
отличаемся. Ultrademo ближе всех к детектору изменений из этапа 5.

## Чего не делаем

- Агент, который сам снимает ролик по URL без сценария. Убивает
  воспроизводимость.
- Облачный рендер. Рендер идет на машине или CI-раннере клиента.
- Редактор видео, таймлайн, ручная правка кадров.
- Озвучка и музыка, пока не закрыты этапы 1-5.
- Запись нескольких вкладок и всплывающих окон.

Если задача тянет в одну из этих сторон, остановись и спроси.

## Модель

- CLI открытый и бесплатный. Это канал привлечения.
- Платный сервис: стабильные ссылки, embed-плеер, история прогонов,
  автообновление из CI, уведомления об изменениях.
- Ориентир по цене: 19-49 EUR в месяц для одиночек, дороже для команд.
